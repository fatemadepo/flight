
# SkyWay – Flight Booking

A responsive frontend flight booking demo built with HTML, CSS, Bootstrap, and JavaScript.

## Features

- Responsive navigation.
- Dynamic flight cards.
- Flight selection.
- Booking summary.
- Automatic price formatting.
- Client-side form validation.
- Responsive layout.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open index.html in your browser.

## Important

This is a frontend demonstration project.

It does not connect to a real flight API, backend, database, reservation system, or payment gateway.

Flight information is sample data.
